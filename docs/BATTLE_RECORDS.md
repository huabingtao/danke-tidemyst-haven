# 战绩和全站统计

## 统计口径

消耗 = 当前棋盘已确认的宝石与数字 0–8 的格数，每格一枚；同格修改不累加，单格重置后扣除。安全格、旗标、推断结果、未确认识别候选不算消耗。找到 = 已确认宝石数。命中率 = 找到 / 消耗；收集完成率 = 找到 / 地图总宝石。显示整数四舍五入，零分母显示“—”。真实样本 31 枚 / 14 宝石 / 总 20 得到 45% 和 70%。

## 生命周期

每个房间有 roundId。当前战绩可随时分享，标记进行中。结束本局保存独立最终记录；修改后再次结算按同一 roundId 更新，整盘重置产生新局。删除房间、重置或继续编辑不改变已保存最终记录。历史最多 1000 条，达到上限提示备份而不默默丢弃。

“已结算”表示当前统计与记录一致；修改导致数量或房间号不同则显示“有修改待重新结算”。分享当前仍是实时阶段快照，分享历史则是最终快照。每份生成的图片/链接固定，重新结算也不修改旧分享。

累计从手选最终记录计算，各局消耗、找到、总宝石分别求和再计算比例。统计不平均百分比，也不自动猜测多张截图是否属于同一局；同一物理游戏的多房间副本请只选最终一份。

## 保存与迁移

v2 JSON 包含 boards/activeId/records，向后读 v1。浏览器从 `tidemyst-boards-v1` 迁移至 `tidemyst-boards-v2`，保留旧键以便回滚；新编辑不会同步旧键。线上回滚旧版本会看到升级前缓存，新版记录仍保留在 v2；跨域或清除缓存不会自动恢复，请导出 JSON。撤销/重做覆盖结算和棋盘操作，本次会话有效；全站统计不会因本地撤销而减少。

## 在线与累计

匿名浏览器 ID 在 localStorage 内，多标签共享；每 30 秒可见页面心跳，90 秒无心跳离线。在线不是登录人数，同人跨设备可能多计；清理缓存会生成新身份。服务重启在线暂时归零，之后随心跳恢复。

累计 = 首次点击结束本局并收到服务器确认的局数。SQLite 对匿名浏览器 ID + roundId 联合哈希唯一去重，重复点击/重新结算/网络重试不增加。同局若在另一浏览器结算仍可能多计，这是无登录统计的边界；并非可审计排行榜。上线前历史不回填、不虚构。用户可主动修改/调用开放接口，首版没有游戏官方校验或反作弊系统。

离线完成先存有限待补报队列，恢复联网后重试；存储拒绝时仅本次会话内保留。统计不可用时页面显示提示，全部本地棋盘/战绩功能继续工作。只读战绩访问计活跃浏览器，不算完成局数。

服务持久化匿名联合哈希与完成时间，不保存原始标识、棋盘、图片或战绩内容。图片识别和 PNG 生成仍全部本地进行。二维码与复制框的只读链接完全相同，片段可被任何持有者读取。
