# 精确概率算法

## 规则与输入

每个未知格子变量 xᵢ ∈ {0,1}。已发现宝石固定为 1；数字和已知安全格固定为 0。数字 n 表示周围至多八个邻居中的宝石数量。用户旗标仅是笔记，不参与约束。

假设符合全部线索和宝石总数的隐藏布局等可能。这是概率模型的先验，不声称知道游戏内部的生成随机分布。

## 约束与传播

对数字格构建 `sum(相邻未知变量) = 数字 - 相邻已发现宝石数`。扣除已固定变量后，检测右侧为负、超过可用变量数、相同集合目标不同等矛盾。

目标为 0 时集合全为空；目标等于集合长度时全为宝石。约束 A 是 B 子集时，建立 B\A 的差约束。反复归一化、传播，并结合全局剩余宝石总数为空/全满的情况确定变量。若局部确定结果无法满足总数，直接报告冲突。

## 分区与枚举

变量共享数字约束形成图，按连通分量拆分。每个分量先按参与的约束集合分组：属于完全相同约束的格子可交换。DFS 对一组 n 格只枚举宝石数量 k（0～n），而非分别遍历每格的 0/1 排列，维护约束已赋之和与剩余变量数并剪枝。组内每种数量贡献 C(n,k) 个布局；单个格子的命中数贡献 C(n−1,k−1)，通过 BigInt 精确累计，再执行原有全局组合权重合并。不同约束集合的格子不会合并。

每个区域生成：

- ways[k]：该区域恰有 k 颗宝石的合法方案数。
- hits[i][k]：其中格子 i 有宝石的方案数。

这些计数均为 BigInt，不存在大组合数的浮点溢出。未受约束格子的数量为 U，选择 u 颗的权重为 C(U,u)。

## 全局组合权重

设剩余宝石数量为 R，各区域宝石数为 k₁…kₘ：

`Z = Σ (∏ ways[j][kⱼ]) × C(U, R - Σ kⱼ)`

对区域 j 的格子 i，将公式里该区域的 ways 替换为 hits[i]，再除以 Z 得到概率。对于自由格子，组合权重替换为 `C(U-1, R-Σkⱼ-1)`。

使用前后缀多项式卷积动态规划避免重复遍历区域宝石数量的笛卡尔积。不能对各分量结果简单平均，也不能忽略自由格子的组合权重。Z=0 表示不存在合法布局。

全新 8×8/20 的概率为 20/64=31.25%；10×10/30 为 30%；12×12/45 为 31.25%。找到宝石后从 R 扣除，但不改变总数设置。

## 输出精度和预算

精确指所有合法布局的计数完整。最终显示概率为约 15 位小数的 Number；仅当分子为 0 或等于分母，才输出严格的 0 或 1。其余比值保持严格位于 (0,1)。界面采用 Math.round(p×100) 显示整数，但只有严格 0/1 使用确定空/确定宝石样式；四舍五入显示为 100% 的不确定格子不会使用“确定”标记。推荐使用未取整数值。

每次求解最多 200 万枚举节点或 5 秒，主 UI worker 另设 12 秒超时。达到预算返回 limited 和全 null 概率，丢弃整个未完成计数，不将已枚举部分当作合法样本。当前没有近似模式。

## 推荐

先选原始概率最高且未记录实际结果的格子，不以四舍五入后的百分比判定并列。严格概率为 1 时，所有确定宝石都高亮；其余情况高亮一个首选，其他同概率位置可以展开查看。

同概率时按下一次观测结果的信息熵排序：结果空间为宝石或数字 0–8，H=−Σp(o)log₂p(o)。每个观测按条件完整合法布局数/Z 加权。该信息量用于区分同概率操作，不改变“优先获得宝石”目标，也不是全局最短操作次数的保证。

若推导后的不确定变量数为 U、剩余宝石 R，且 Z=C(U,R)，则所有这类放置均合法。用超几何组合直接得到各结果的权重：宝石 C(U−1,R−1)；数字 n 为 C(d,n−k)C(U−1−d,R−n+k)，其中 d 是未定邻居数，k 是已确定相邻宝石数。

其他情况，对最高概率候选的宝石/0–8 分别执行条件精确求解，计数之和必须为原布局总数。信息比较默认预算 1800ms，每次条件枚举最多 80000 节点/120ms。任何未完成计数都会使整次排序回退到“未定邻域覆盖”，UI 明确解释回退；不会用部分计数冒充精确信息量。该任务和求解一起在 Worker 运行。无合法结果时不给推荐。

## 交叉验证

独立 brute-force oracle 枚举小棋盘全部 bitmask，验证总数和所有数字约束，再直接统计每格有宝石次数。测试包括共享线索、可变宝石数的约束区域、多独立区域、自由变量和不同全局总数；对 171 个有效 3×3 隐藏布局生成观测逐格比对。预算中断和矛盾单独检验，不允许有效概率泄漏。

新增真实截图还原回归：12×12、45 宝石、已发现 20、G11 录入 2 后，原实现达到 2,000,001 节点返回 limited；分组实现只访问 131 节点并精确完成。对 G11 宝石及 0～8 的所有条件结果，验证布局总数之和等于录入前总数、概率加权还原原棋盘，且所有数字邻域概率和与线索一致。

推荐排序另与独立小棋盘观测结果枚举对照；包含空白 B2、已知 0 远离安全邻域、确定宝石优先及预算回退。
