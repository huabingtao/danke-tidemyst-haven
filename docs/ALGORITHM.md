# 精确概率算法

## 规则与输入

每个未知格子变量 xᵢ ∈ {0,1}。已发现宝石固定为 1；数字和已知安全格固定为 0。数字 n 表示周围至多八个邻居中的宝石数量。用户旗标仅是笔记，不参与约束。

假设符合全部线索和宝石总数的隐藏布局等可能。这是概率模型的先验，不声称知道游戏内部的生成随机分布。

## 约束与传播

对数字格构建 `sum(相邻未知变量) = 数字 - 相邻已发现宝石数`。扣除已固定变量后，检测右侧为负、超过可用变量数、相同集合目标不同等矛盾。

目标为 0 时集合全为空；目标等于集合长度时全为宝石。约束 A 是 B 子集时，建立 B\A 的差约束。反复归一化、传播，并结合全局剩余宝石总数为空/全满的情况确定变量。若局部确定结果无法满足总数，直接报告冲突。

## 分区与枚举

变量共享数字约束形成图，按连通分量拆分。每个分量按约束度数排序变量，DFS 分支赋 0/1，维护约束已赋之和与剩余变量数；如果目标不在可达到区间内，立即剪枝。

每个区域生成：

- ways[k]：该区域恰有 k 颗宝石的合法方案数。
- hits[i][k]：其中格子 i 有宝石的方案数。

这些计数均为 BigInt，不存在大组合数的浮点溢出。未受约束格子的数量为 U，选择 u 颗的权重为 C(U,u)。

## 全局组合权重

设剩余宝石数量为 R，各区域宝石数为 k₁…kₘ：

`Z = Σ (∏ ways[j][kⱼ]) × C(U, R - Σ kⱼ)`

对区域 j 的格子 i，将公式里该区域的 ways 替换为 hits[i]，再除以 Z 得到概率。对于自由格子，组合权重替换为 `C(U-1, R-Σkⱼ-1)`。

使用前后缀多项式卷积动态规划避免重复遍历区域宝石数量的笛卡尔积。不能对各分量结果简单平均，也不能忽略自由格子的组合权重。Z=0 表示不存在合法布局。

全新 8×8/20 的概率为 20/64=31.25%；10×10/30 为 30%；12×12/45 为 31.25%。找到宝石后从 R 扣除，但不改变总数设置。

## 输出精度和预算

精确指所有合法布局的计数完整。最终显示概率为约 15 位小数的 Number；仅当分子为 0 或等于分母，才输出严格的 0 或 1。其余比值保持严格位于 (0,1)，界面不会因为四舍五入将其显示为确定空/确定宝石。

每次求解最多 200 万枚举节点或 5 秒，主 UI worker 另设 12 秒超时。达到预算返回 limited 和全 null 概率，丢弃整个未完成计数，不将已枚举部分当作合法样本。当前没有近似模式。

## 推荐

第一策略显示全部最高宝石概率格子，坐标列表最多先展示 12 个。第二策略单独提供邻域覆盖参考：在未定格子中，按未定相邻格子数排序，同覆盖量优先较低宝石概率，再以坐标稳定排序。安全未知格子也可用于覆盖参考。

覆盖策略不是精确信息熵，也不保证下一次取得宝石。无合法结果时不给出推荐。

## 交叉验证

独立 brute-force oracle 枚举小棋盘全部 bitmask，验证总数和所有数字约束，再直接统计每格有宝石次数。测试包括共享线索、可变宝石数的约束区域、多独立区域、自由变量和不同全局总数；对 171 个有效 3×3 隐藏布局生成观测逐格比对。预算中断和矛盾单独检验，不允许有效概率泄漏。
