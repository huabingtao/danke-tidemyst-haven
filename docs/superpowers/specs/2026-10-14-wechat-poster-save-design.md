# 微信战绩保存修复

用户要求战绩卡片只保留“下载图片”和“复制战绩链接”；移除系统图片/链接分享与常驻只读链接输入框。复制受限时才弹出手动复制窗口，保留完整链接。

旧预览为 blob URL，微信原生保存可能无法在网页 JavaScript 上下文之外获取字节。这是基于错误现象的兼容性判断，并非已取得真机日志。推荐普通同源 HTTPS PNG，避免仅改为 data URL 后仍受宿主限制；无需配置公众号签名 SDK。

仅微信环境自动上传生成的战绩 PNG 到本工具服务器，24 小时后清理；游戏截图仍不上传。网页显示此临时图片用途。非微信仍本地生成和下载。微信下载按钮打开原生 dialog 大图，长按图片保存；预览使用普通 img，开启 touch-callout，不用 Canvas 覆盖触摸。真实微信的保存菜单由宿主提供，自动化只能验证 HTTPS 图片条件，不能宣称相册已保存成功。

新增 /api/battle-images POST 与不可猜的 PNG GET 地址，2MB、1080×1440 PNG 格式校验、同源校验、60 次/小时/IP、128MB/512 文件上限。服务器文件独立于版本，过期清理与重启恢复；不修改完成局数。上传失败保留本地图片与复制能力，下载按钮可重试。不存在“已保存成功”的假提示。

沿用当前黄蓝样式与弹窗焦点/关闭交互，不改统计、求解和识别。用户此前授权后续选项均按推荐方案执行，按此方案直接实现与发布。
