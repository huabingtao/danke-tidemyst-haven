# 当前进度与工具分享

用户已要求完成重置/自适应后增加分享，确认暂无公开域名，部署后自动使用正式地址。无需后台、账号、收费 API 或自动发送群消息。

- [x] 当前房间数据用版本化短码写入 URL fragment：尺寸、总宝石、房间号、真实观察、旗标；不包含原图、识别候选或求解缓存。每格一个字符，总链接长度有限。
- [x] 打开链接验证并恢复成独立房间，不覆盖已有房间。快照 ID 根据内容稳定，重复打开/刷新不重复导入，用户自己的后续编辑保留。异常和超长链接提示错误。
- [x] 工具链接清除进度片段。默认使用当前页面正式 origin/path，允许 VITE_PUBLIC_APP_URL 覆盖；本地地址明确为测试链接。
- [x] 增加一键分享当前进度与分享工具：支持环境打开原生系统分享，取消不误报成功；其他环境复制链接，失败时打开可复制的弹窗。
- [x] 微信签名配置由独立 adapter 注入，updateAppMessageShareData 只设置菜单资料，不宣称自动发群；小程序 web-view 接入说明保持独立，未配置时可复制链接。
- [x] 验证编解码、所有状态与旗标、异常输入、URL路径和不可变快照、恢复/去重/保持原房间、工具链接、复制失败降级、分享取消；结合重置/自适应做全量测试、构建及一次桌面/移动截图检查。

官方核对：微信 JS-SDK 新文档 https://developers.weixin.qq.com/doc/service/guide/h5/jssdk.html；小程序 web-view https://developers.weixin.qq.com/miniprogram/dev/component/web-view.html。上线签名和真机转发需正式部署环境，本阶段实现 H5 侧完整编码/恢复/原生分享/复制及可注入接入点。
