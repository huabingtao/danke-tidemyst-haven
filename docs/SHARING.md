# 进度与工具分享

## 使用和部署

棋盘工具栏“分享当前进度”保存点击时的当前房间；顶部“分享工具”只分享工具入口。支持 Web Share 的环境打开系统面板，由用户选择微信和接收人；其他环境复制链接并提供可编辑选中的链接弹窗。取消系统分享不会复制或提示已发送。剪贴板受限时可长按手动复制。

默认取当前页面 origin/path，部署到公开 HTTPS 服务后自动变为正式链接。localhost、回环和常见局域网地址显示测试提示。无需现在提供域名，静态部署后可直接使用。可选构建变量 `VITE_PUBLIC_APP_URL` 设定固定入口，必须是 HTTP(S) 完整地址；推荐 HTTPS 和末尾 `/`。域名能否从公网访问仍由部署方负责。

## 快照与恢复

URL 结构是 `https://站点/路径/#progress=短码`。版本 1 数据包含尺寸、总宝石数、房间号、每格真实观察与独立旗标；24 字符字母表表示 12 种观察 × 2 种旗标。JSON 经 UTF-8/base64url 编码，不加密。不要在房间号填写私密信息。没有原图、识别候选、房间内部 ID 或计算缓存。

接收者打开链接时验证版本、长度和全部模型，创建独立房间再求解；其他已有房间保留。同一内容使用稳定指纹 ID，重复打开/刷新复用接收者已有副本，保留其修改。要恢复最初快照，可先删除接收副本再重新打开。分享者之后编辑不改变已生成链接，多房间需逐个分享。链接损坏只提示错误，不覆盖数据。

片段不随普通 HTTP 请求发送，静态服务无需分享数据库。链接持有者可读取快照；群聊平台是否保留片段、是否生成卡片以及系统是否提供微信目标，仍需正式地址和真机验证。

## 微信接入点

当前完整可用路径是系统分享或复制链接到群。H5 不提供自动选择微信群和发送的接口。可选 `installWechatSharing(sdk, config, imageUrl)` 注入已加载官方 SDK、签名和公开封面 URL。`config` 包括 appId、timestamp、nonceStr、signature；签名应由部署方服务端取得，不在纯前端保存 appSecret。

适配器请求 `updateAppMessageShareData` 权限，等待 ready，设置标题、描述、链接、封面；成功仅表示菜单资料已设置，再由用户点微信右上角菜单发送。失败或未就绪回退复制。部署方需要按 [微信 JS-SDK 官方文档](https://developers.weixin.qq.com/doc/service/guide/h5/jssdk.html) 验证 URL 签名、域名与权限，尤其是页面片段变化时的签名规则。

小程序 web-view 仅支持官方列出的 JS-SDK 子集，不能直接把普通微信 H5 的菜单配置当成小程序分享能力。未来壳工程应按 [web-view 官方文档](https://developers.weixin.qq.com/miniprogram/dev/component/web-view.html) 配置 onShareAppMessage、webViewUrl 和通信。postMessage 的接收有生命周期时机限制；本阶段没有开发小程序壳或签名服务。

## 已验证范围

单元测试覆盖三尺寸编解码、中文房间名、全部观察/旗标、无效输入、路径和快照独立性，原生分享、取消、能力检测异常、复制回退、本地提示和注入 SDK 菜单资料。Chromium 桌面/手机与 WebKit 手机自动化验证分享恢复、去重、编辑保留、工具链接、复制及失败降级。未用真实微信账号发送到群，未验证正式业务域名的 SDK 签名。

## 战绩图片与只读链接

“我的战绩”支持当前进行中、单局最终、手选多局累计。点击生成时固定原始数量，后续修改不影响图片或链接。`#battle=短码` 只包含版本、状态、房间/局数、消耗、宝石数量、总量和日期；不含棋盘。接收者只读浏览，不导入或覆盖现有房间。链接片段不加密，持有者可读摘要。

1080×1440 PNG 在本地 Canvas 生成；二维码与复制框指向完全相同的正式只读链接，二维码自动保留静区。文件分享可用时调用系统面板，取消不提示发送成功。受限时下载或展示图片供长按保存，链接仍支持复制/手动复制。PNG 不上传，统计服务也不承担分享存储。二维码库遵循其 [官方 API](https://github.com/soldair/node-qrcode)。

统计只记录匿名完成事件；累计战绩卡片仍由用户手选本机记录，与全站累计完成局数是两个不同指标。真实微信发送、长按保存和菜单 SDK 签名仍需真机验证。
