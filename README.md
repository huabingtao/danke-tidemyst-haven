# 潮汐秘境 · 宝石推理助手

独立中文 H5：手动录入或从截图读取棋盘，按真实数字和宝石总数推算每格宝石概率。棋盘、识别、战绩和分享均在浏览器本地处理，无登录或付费 AI API。独立轻量统计服务提供在线人数与累计完成局数，不接收棋盘或图片。

正式入口：[dankecxmj.guaguahub.cn](https://dankecxmj.guaguahub.cn/)。已部署腾讯云 Nginx，HTTPS 证书自动续期；更新和回滚见 [部署记录](docs/DEPLOYMENT.md)。

## 本地启动

需要 Node.js 22.13+（统计服务使用内置 node:sqlite）（本次验证为 Node 24.11.1）。

```bash
npm ci
npm run dev
# 另开终端，启动可选的人数统计服务
npm run dev:stats
```

打开终端显示的地址，默认 `http://localhost:5173`。手机同局域网可打开电脑的局域网 IP 与端口；正式部署应使用 HTTPS。

`npm ci` 的 postinstall 自动从 npm 依赖复制 OCR worker、WASM 与英语数字模型到 `public/ocr/`。这些文件不纳入源码版本；离线构建前需准备 npm 依赖缓存。运行时没有第三方 OCR CDN 依赖。

## 使用

1. 新建 8×8 / 10×10 / 12×12 房间，设置棋盘的总宝石数。
2. 点击格子，在弹窗中选择宝石或 0–8；选择后自动关闭。“重置此格”恢复未知并清除旗标和识别候选，支持撤销。旗标与擦除也位于棋盘工具栏。8/10/12 棋盘根据容器实时适配，所有列完整显示，没有棋盘内部滚动条。
3. 概率四舍五入显示整数，原始精度用于排序。推荐格子高亮，优先最高概率，同概率比较观测信息量；可展开查看其他并列位置。点击推荐位置记录实际结果。
4. 电脑点击读取截图直接上传；手机可选相册或拍照，另支持拖拽、粘贴、多图。上传后自动判断 8/10/12 尺寸、定位并识别，成功后关闭进度弹窗并填入新房间。无需参数或开始按钮。低置信度内容保留候选提示，点击主棋盘核对；定位失败时提示换完整截图。
5. 所有房间自动保存在当前浏览器；导出 JSON 可备份和迁移。撤销 / 重做支持本次会话中的编辑、重置、删除和导入；刷新后恢复房间数据，编辑历史不跨刷新。
6. 棋盘工具栏的“分享当前进度”生成当前房间快照；顶部“分享工具”生成入口链接。支持系统分享时打开分享面板，否则复制链接或显示可手动复制的弹窗。接收者打开进度链接即可继续编辑，不覆盖其已有房间。分享是这一刻的快照，后续修改不会同步。

7. 顶部“我的战绩”查看棋子消耗、找到宝石、命中率和收集完成率；“结束本局”保存最终记录。同一局重新结算更新原记录，整盘重置开启新局。手选多局分享累计成绩；分享图片可下载或在手机长按保存。只读战绩链接不会导入接收者棋盘。
8. 在线人数按最近 90 秒活跃的匿名浏览器统计，每 30 秒刷新；累计完成按首次结算去重。从统计服务上线开始累计，不追溯旧历史。服务离线仍可编辑和保存战绩，待恢复补报完成事件。

「推测」旗标不参与概率约束。没有看到数字时不要误填为 0。旧 JSON 中的安全观测仍兼容。图例覆盖已发现宝石、数字、概率、推荐、确定宝石、确定空、旗标与矛盾数字。

## 验证

```bash
npm test
npm run test:server
npx playwright install chromium webkit
npm run test:e2e
npm run build
npm run preview
```

Vitest 覆盖约束、组合计数、小棋盘暴力 oracle、房间存储、网格定位与像素分类。Playwright 覆盖 Chromium 桌面/手机视口和 WebKit 手机视口，包括实际同源 OCR、自动填入、刷新恢复、存储失败、取消等流程。自动化内核测试不代表微信或 iPhone 真机已验收。

重新生成可公开的合成识别素材：`node scripts/generate-fixtures.mjs`。未使用原网站图像资源或代码。真实回归样本由用户提供，仅用于测试；生产仅包含校准字形掩码。重新校准可运行 `node scripts/calibrate-game-glyphs.mjs`。

## 生产部署

`npm run build` 生成 `dist/`，上传整个目录到任意静态 HTTPS 服务，包含 `ocr/` 子目录。静态部署保留全部棋盘和分享功能；在线人数与全站累计局数需部署 `server/stats.mjs`，同源反向代理 `/api/stats`，示例 systemd 和 Nginx 配置见 `deploy/`。不要用 `file://` 直接双击 HTML，Web Worker 和存储需要正常 HTTP(S) origin。

Vite 使用相对 base，可部署到域名根目录或 `/tidemyst/` 子目录；网页路径末尾使用 `/`，避免资源解析到父目录。WASM 资源需正确返回 `application/wasm`，JS 需正确 JavaScript MIME 类型。不要将缺失的 OCR 文件回退成 `index.html`。

分享默认自动使用当前页面的域名和路径，部署后无需另填地址。本地 localhost / 局域网只提供测试链接，无法让群友从公网打开。需要指定固定入口时，参考 `.env.example` 设置 `VITE_PUBLIC_APP_URL=https://你的域名/tidemyst/` 后重新构建。进度放在链接片段中，不需要分享后台。微信菜单分享卡片的可选 SDK 接入与签名要求见 [分享说明](docs/SHARING.md)。

若服务器启用 CSP，需允许同源 JS / worker、`blob:` worker，以及 WASM 编译（现代浏览器 `wasm-unsafe-eval`）。生产策略应在实际宿主中验证。缓存可设置带 hash 的 `assets/` 长期缓存；OCR资源部署更新时同步刷新缓存，HTML 短缓存。

## 功能与边界

- 已实现：阶段/最终/累计战绩、独立记录、高清 PNG 与只读二维码链接、黄蓝浅深主题、匿名在线人数与累计完成局数；三种自适应棋盘、多房间、单格重置、真实状态与旗标分离、自动保存、撤销重做、JSON 备份、精确后台求解、三种视图、冲突提示、中文浅深主题、移动触控、本地截图识别与人工校正、进度快照与工具分享链接。
- 已实现、仍需真实素材验证：已用用户真实 8×8 截图及四种变体逐格验证 64 格，支持金色宝石、蓝色盖板和白色描边数字。真实 10/12、其他皮肤、真实 0/5–8、严重模糊、实际相机和微信 WebView 能力仍需更多样本/设备验证；单一样本不代表通用准确率。
- 设计边界：精确枚举超出预算会停止并提示，不输出截断概率；信息推荐优先完整计算宝石/数字观测的熵，超过独立预算时明确回退邻域覆盖。倾斜透视照片请换正面截图；不确定空白一律保留未知。
- 本阶段未开发：微信小程序壳、JS-SDK 业务接入、登录支付；也没有透视自动矫正、近似采样求解。
